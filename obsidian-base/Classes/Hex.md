# FileClass: Hex

Use esta classe nos arquivos dentro de `Campanhas/.../Hexes`.

Campos principais:

- `hex`
- `nome`
- `terreno` → link para `Catalogos/Terrenos`
- `perigo` → link para `Catalogos/Perigos`
- `exploracao` → link para `Catalogos/Exploracoes`
- `feature_estrada`, `feature_rio`, `feature_trilha`
- `poi_tipo` → link para `Catalogos/Pontos de Interesse`
- `poi_nome`
- `poi_estado` → link para `Catalogos/Estados de POI`
- `faccao_id`
- `faccao_nome`
- `faccao_controle` → link para `Catalogos/Controles de Faccao`
- `faccao_relacao` → link para `Catalogos/Relacoes de Faccao`

Para editar sem digitar errado, rode o template `Editar Hex Atual.md` com o Templater.
