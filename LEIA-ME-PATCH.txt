Patch para aplicar na raiz do repo Hex-Viewer.

Arquivos principais:
- script.js: passa a aceitar ?data=data-jogadores, ?data=data-mestre e ?manifest=...
- tools/hex_export_tool.py: exportador unificado atual.
- termux/servir_site.sh: servidor local para Termux.
- .gitignore: ignora backups, perfis de exportação locais, build Python e IDE.

Como aplicar:
1. Extraia o conteúdo deste zip diretamente na raiz do repo.
2. Permita sobrescrever arquivos.
3. Rode o site com:
   python -m http.server 8080
4. Teste:
   http://localhost:8080/?data=data
   http://localhost:8080/?data=data-jogadores
   http://localhost:8080/?data=data-mestre
5. Faça git status e commit.
