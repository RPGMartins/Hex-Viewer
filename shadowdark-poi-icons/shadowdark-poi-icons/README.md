# Ícones para Pontos de Interesse — Shadowdark/Hexcrawl

Pacote de SVGs originais, simples e genéricos para representar pontos de interesse, desenvolvimentos e cataclismos em um hexmap.

Arquivos principais:
- `icons/` — SVGs 64x64
- `poi-icons.json` — mapeamento da tabela para os ícones
- `preview.html` — prévia navegável
